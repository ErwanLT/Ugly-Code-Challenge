# Code de conduite — The Ugly Code Challenge

## Notre philosophie

The Ugly Code Challenge est un concours de code volontairement absurde, dans lequel la créativité, l'humour et l'ingéniosité technique sont mis à l'honneur.

Nous encourageons les solutions improbables, les architectures démesurées, les détournements de bonnes pratiques et les implémentations que personne n'oserait défendre en revue de code.

Mais derrière le chaos apparent, une règle demeure : le respect des personnes.

## Les comportements attendus

Chaque participant s'engage à :

- Faire preuve de respect envers les autres participants, quels que soient leur expérience, leur métier ou leurs compétences.
- Privilégier l'humour et l'autodérision, sans jamais viser personnellement un autre participant.
- Accepter les critiques et les plaisanteries sur son code avec bienveillance.
- Formuler ses retours de manière constructive, même lorsque le code présenté met à rude épreuve les principes fondamentaux du développement logiciel.
- Respecter les règles de contribution et les décisions liées à l'organisation du concours.

## Les comportements inacceptables

Ne sont pas tolérés :

- Le harcèlement, les insultes, les menaces ou les attaques personnelles.
- Les propos discriminatoires ou humiliants, quels qu'en soient le motif ou le contexte.
- La publication de données personnelles ou confidentielles sans autorisation.
- Le sabotage volontaire du travail d'un autre participant.
- Toute tentative de manipulation du vote ou de dénigrement d'un concurrent.

## Le code est une cible légitime

Dans le cadre du challenge, le code peut être qualifié de catastrophique, monstrueux, illisible, aberrant ou techniquement indéfendable.

C'est même parfois le but recherché.

En revanche, ces qualificatifs concernent exclusivement la production technique et ne doivent jamais devenir des attaques contre leur auteur.

## Modération

Les organisateurs se réservent le droit de supprimer tout contenu contraire à ce code de conduite, de demander sa modification ou d'exclure un participant en cas de comportement grave ou répété.

Les signalements peuvent être adressés directement aux organisateurs, de manière privée.

Toute décision sera prise avec discernement, dans l'intérêt du bon déroulement du challenge.

## En résumé

Écrivez du code dont vous aurez honte demain.

Défendez des choix techniques que vous ne recommanderiez à personne.

Faites rire vos collègues.

Mais n'oubliez jamais que derrière chaque ligne de code, même la plus atroce, il y a quelqu'un.

**Be ugly with code, not with people.**
