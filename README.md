# 🏆 Ugly Code Challenge

Bienvenue dans l'Ugly Code Challenge !

Un concours de développement où l'objectif est simple : écrire le code le plus improbable possible, tout en produisant une solution qui fonctionne réellement.

## Le concept

Tous les trimestres, un nouveau défi est proposé aux participants.

Les règles sont simples :
- Un seul défi par édition.
- Un thème différent à chaque édition.
- Langage et framework totalement libres.
- Une seule participation par candidat et par édition.
- Le code doit fonctionner.
- Le candidat doit pouvoir présenter et expliquer sa réalisation.

Ici, on ne récompense pas le code le plus propre, mais la créativité dans l'art de produire du code volontairement discutable.

## Comment participer ?

1. Consultez le thème de l'[édition en cours](./editions/2027/2027-01-ministere-des-excuses/).
2. Forkez le dépôt.
3. Créez votre dossier dans `editions/<année>/<édition>/candidates/<votre-identifiant>/`.
4. Développez votre solution.
5. Ajoutez un README expliquant comment l'exécuter.
6. Ouvrez une Pull Request vers `main`.

## Comment gagner ?

Le gagnant est le participant dont la Pull Request reçoit le plus de réactions 👍 pendant la période de vote.

La popularité de votre code est donc aussi importante que sa qualité... ou son absence de qualité.

## Philosophie

**Make it work. Make it ugly. Make us laugh.**

Le code peut être moche, absurde, incompréhensible ou architecturalement criminel.

Mais il doit fonctionner.
